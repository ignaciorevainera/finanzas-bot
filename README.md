## Project Overview

This repository contains the source code for an automated personal finance tracking bot deployed via Telegram.

20: The system uses Google Gemini AI (`gemini-3.5-flash` by default through the official `google-genai` SDK) to parse natural language inputs (text and voice notes via direct multimodal input) and extract structured financial transaction data.
21: 
22: Extracted data is stored in a serverless PostgreSQL 18 database on Neon. The application is implemented in Python with FastAPI, deployed continuously on Render, and runs with a webhook-based architecture.
23: 
24: ## Architecture Summary
25: 
26: - **Structure:** Modular `app/` package layout.
27: - **User scope:** Single-user deployment with no authentication layer.
28: - **Audio pipeline:** Direct multimodal processing with Gemini (no external transcription service).
29: - **Interaction language:** Bot responses in Spanish; codebase strictly in English.
30: - **Confirmation flow:** Inline keyboard actions (Confirm/Cancel) before DB persistence.
31: - **AI engine:** `gemini-3.5-flash` (configurable) with `google-genai`.
32: - **Schema management:** Automatic table initialization on startup.
33: - **Monitoring:** Structured logging (`logging`) and `GET /health` endpoint.
34: 
35: ## Technology Stack
36: 
37: - **Language:** Python 3.10+
38: - **Web framework:** FastAPI (webhook handling)
39: - **Telegram integration:** `python-telegram-bot` (async)
40: - **AI processing:** Google Gemini API (`google-genai`, model `gemini-3.5-flash`)
41: - **Database:** PostgreSQL 18 (Neon serverless) via `asyncpg`
42: - **Deployment platform:** Render (Free Web Service)
43: 
44: ## Bot Commands
45: 
46: - `/start`: Initialize interaction and webhook context.
47: - `/help`: Show available commands and usage guidance.
48: - `/summary`: Generate financial summaries and category aggregations.
49: - `/recent`: List recent transactions.
50: - `/delete`: Remove specific transaction records.
51: - `/export`: Export transaction history in structured format.
52: 
53: ## Development Standards
54: 
55: - **Codebase language:** All source code artifacts (variables, functions, DB schemas, attributes) must be in English.
56: - **Security:** Hardcoded credentials are forbidden. Sensitive data must come from environment variables only.
57: 
58: ## Database Schema (PostgreSQL 18)
59: 
60: The system uses a strict relational schema to preserve transactional integrity.
61: 
62: ```sql
63: CREATE TABLE transactions (
64:     id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
65:     type VARCHAR(10) NOT NULL CHECK (type IN ('income', 'expense')),
66:     amount DECIMAL(12, 2) NOT NULL,
67:     currency VARCHAR(3) NOT NULL DEFAULT 'ARS',
68:     category VARCHAR(100) NOT NULL,
69:     merchant VARCHAR(255),
70:     payment_method VARCHAR(50) NOT NULL,
71:     status VARCHAR(20) NOT NULL DEFAULT 'completed' CHECK (status IN ('completed', 'pending', 'cancelled')),
72:     tags TEXT[],
73:     location VARCHAR(255),
74:     notes TEXT,
75:     created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
76:     updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
77:     original_message TEXT
78: );
79: ```
80: 
81: ## Environment Variables
82: 
83: Define the following variables in the runtime environment (Render) or local `.env` file:
84: 
85: - `TELEGRAM_BOT_TOKEN`: Token generated by BotFather.
86: - `GEMINI_API_KEY`: API key from Google AI Studio.
87: - `GEMINI_MODEL`: Model name (default: `gemini-3.5-flash`).
88: - `DATABASE_URL`: Neon PostgreSQL 18 URI with embedded username/password.
89: - `WEBHOOK_URL`: `https://finanzas-bot-48c4.onrender.com`
90: - `PYTHON_VERSION`: `3.10.0` or higher (async compatibility on Render).

## Deployment (Render)

Deployment is handled via continuous integration on Render.

### Required repository files

- `requirements.txt`: All Python dependencies.
- `.gitignore`: Must exclude local envs (`venv/`), cache files (`__pycache__/`), and secrets (`.env`).

### Render configuration

- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
